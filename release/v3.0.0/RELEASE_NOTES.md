# CoreG Website v3.0.0 Release Notes

**Release theme:** Institutional Identity

## Summary

Version 3.0.0 establishes the CoreG website as a formally managed institutional software release. It locks the approved CoreG identity and hero statement, introduces responsive navigation safeguards, formalizes accessibility and interface standards, and adds the documentation required for repeatable release, validation, deployment, and rollback.

## Canonical language

> CoreG facilitates qualifying private capital transactions through a disciplined operating standard built to ensure confidence, integrity, and accountability from first engagement through close.

## Included changes

- Approved hero statement enforced across source content.
- Responsive header and navigation hardening for narrow and desktop-site viewports.
- Minimum touch-target and keyboard-focus standards.
- Reduced-motion support.
- Design system documentation.
- Release process documentation.
- Testing and deployment documentation.
- Engineering journal.
- Release-candidate validation tooling.
- Timestamped rollback backup during installation.

## Deployment status

Release package is prepared for installation into the current `coregenisis-site` repository. Production promotion remains subject to successful local build and visual validation.
