# CoreG Website Validation

## Build

- Install dependencies from the lockfile.
- Run the production build.
- Confirm the build exits successfully.
- Confirm no required route or asset is missing.

## Content

Verify the canonical statements:

- CoreG is an authorized intermediary serving private capital markets.
- Truth in Transactions is our operating standard.
- CoreG facilitates qualifying private capital transactions through a disciplined operating standard built to ensure confidence, integrity, and accountability from first engagement through close.

## Navigation

Verify every primary route opens at the top of the destination page and remains keyboard accessible.

## Responsive matrix

- Android Chrome portrait.
- Android Chrome landscape.
- Android Chrome desktop-site mode.
- Tablet portrait and landscape.
- Desktop at 1280px and 1440px.
- Narrow viewport at 320px.

## Accessibility smoke tests

- Keyboard-only navigation.
- Visible focus state.
- No horizontal page scrolling at 320px.
- Interactive targets remain usable on touch screens.
- Reduced-motion preference does not impair navigation.
