# CoreG Design System

## Principles

CoreG's public interface should communicate institutional discipline, clarity, and restraint. Visual choices must support comprehension and confidence rather than novelty.

## Typography

- Page titles: concise, high contrast, and limited to a readable line length.
- Section headings: sentence case and structurally descriptive.
- Body copy: 16px minimum on small screens, with comfortable line height.
- Long-form text: target 60–75 characters per line.

## Spacing

Use a consistent vertical rhythm. Major sections should remain visually distinct without excessive empty space. Mobile layouts should reduce scale rather than compress content.

## Buttons

- Primary: reserved for the principal conversion action, normally Request Access.
- Secondary: used for pathway navigation and supporting actions.
- Minimum interactive target: 44 × 44 CSS pixels.
- Every interactive element requires a visible keyboard focus state.

## Cards

Cards must use consistent internal spacing, heading hierarchy, and action placement. Equal-height presentation may be used within a row where it improves comparison, but content must not be artificially truncated.

## Responsive behavior

- Navigation must reflow rather than scale down.
- Brand marks must retain legibility.
- Text must not require horizontal scrolling at 320px viewport width.
- Desktop-site mode on a narrow Android viewport must remain usable.

## Accessibility

- Preserve semantic landmarks.
- Maintain visible focus indicators.
- Use meaningful link text.
- Respect reduced-motion preferences.
- Maintain sufficient text/background contrast.
